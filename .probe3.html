申请友链

1

添加本站友链

请先在您的网站友链页面添加本站信息，可直接复制左侧各字段

2

先 Fork 仓库，再加入你的条目

点下面按钮 Fork 本仓库，然后打开你 Fork 出来的那份仓库，在 data/friends/ 下新建一个 JSON 文件（文件名用你站点的短名，如 your-blog.json），内容照下面模板填。

简介（description）最多 100 字；没有头像就填 null。

填好后从你自己的仓库向本仓库提交 Pull Request。Action 会自动校验格式，并访问你填写的那个页面检查是否已放本站链接（下方任一域名都算），结果会贴在 PR 里 —— 只做提示，最终由站主合并。

{ "name": "你的站点名", "avatar": "https://你的头像地址.png", "description": "一句话简介（可选）", "url": "https://你的站点/", "backlink": "https://你站点上放了本站链接的那个页面（可选）" }

Fork 仓库，添加友链

3

等 PR 被合并

合并后你的友链就会出现在下方列表 —— 本站每次构建都会重新拉取友链仓库的数据，无需再改站点代码

注意事项

互换原则：请先将本站添加到您的友链页面，确认后会添加您的友链

链接维护：友链网站长期无法访问或内容违规，将会被移除

内容要求：内容积极向上，不含有任何含色情/反动/暴力等违法违规内容

站点要求：支持 HTTPS，以原创内容为主，能够正常访问且有持续更新

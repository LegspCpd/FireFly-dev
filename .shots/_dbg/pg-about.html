服务条款与隐私政策 (Terms of Service & Privacy Policy)#

生效日期：2026年8月25日
适用范围：本网站（legspcpd.top 及相关子域名）、自部署 Macro/API 服务，以及由本站运营的所有第三方平台集成接口（包括但不限于 Google OAuth 客户端、Google API Services 和搜索引擎自动化服务）。

一、 总则与双重效力声明 (General Provisions & Scope)#

  • 1.1 协议一体化：本文件由服务条款 (Terms of Service) 与 隐私政策 (Privacy Policy) 构成统一的法定协议。
  • 1.2 双重适用对象：
    • 自然人用户：访问本站博客、注册账户、使用自部署 Macro 工具或发布内容的普通用户。
    • 第三方平台与自动化服务：包括 Google LLC（含 Google OAuth 审核团队、Googlebot 爬虫、Google API 调用端）、其他搜索引擎、API 消费端及自动化脚本。
  • 1.3 同意效力：任何访问本站、调用本站 Macro 接口、发起 Google OAuth 授权或解析本站 API 的行为，均视为同意并接受本协议的全篇约束。

二、 服务条款 (Terms of Service)#

2.1 服务内容与提供方式#

  • 2.1.1 博客与自部署 Macro：本站提供个人博客内容展示、自部署工具/Macro 接口调用及相关数据处理服务。
  • 2.1.2 服务按“现状”提供：所有服务均基于“原样（As Is）”和“可提供（As Available）”的基础提供。本站保留随时调整、暂停或终止部分或全部服务的权力，且无需另行通知。

2.2 用户行为规范与 API 调用限制#

  • 2.2.1 账户与凭据管理：用户及客户端须妥善保管账户、密码及 API Token。因凭据泄露导致的损失由使用者自行承担。
  • 2.2.2 恶意使用禁止：
    • 严禁通过自动化脚本对本站或 Macro 端点发起 DDoS 攻击、越权访问或超频刷取。
    • 严禁利用本站服务传输任何非法、侵权、恶意软件或未经授权的垃圾数据。
  • 2.2.3 限流与封禁：本站有权根据流量与安全策略对特定 IP、用户或第三方 API 请求实施速率限制（Rate Limiting）或直接封禁。

2.3 用户生成内容（UGC）与知识产权#

  • 2.3.1 内容所有权：用户在其发布的评论、代码片段或提交的数据中保留原始知识产权。

2.4 免责声明与责任限制#

  • 2.4.1 不可抗力与中断：因网络服务商故障、云端基础设施（如 Cloudflare、Vercel）中断、第三方 API 变更或不可抗力导致的服务暂停或数据丢失，本站运营者在法律允许的最大范围内免责。

三、 隐私政策 (Privacy Policy)#

3.1 信息收集范围与方式#

  • 3.1.1 用户主动提交的数据：
    • 账户数据：邮箱地址、用户名、哈希加密后的密码。
    • 交互与提交数据：评论内容、表单反馈及用户通过 Macro 服务主动上传的配置或参数。
  • 3.1.2 自动收集的技术数据：
    • 系统日志：IP 地址、请求报头（User-Agent）、访问时间、HTTP 请求路径及状态码。
    • Cookie / LocalStorage：仅用于维持用户登录会话（Session）与偏好设置。
  • 3.1.3 第三方 API 及 Google 用户数据：
    • 当用户使用 Google 账号登录（Google Sign-In）或授权本站集成应用访问 Google 服务时，本站仅读取该应用功能所必需的最低限度数据（如 Google 用户 ID、电子邮箱、公开基本资料或特定 API Scope 范围内的许可数据）。

3.2 数据使用目的与处理原则#

  • 3.2.1 核心服务提供：用于身份验证、Macro 功能执行、账户管理及响应用户请求。
  • 3.2.2 安全防范与合规：用于监测恶意攻击、防范滥用行为及配合第三方基础服务商的安全防御。
  • 3.2.3 严禁出售数据：本站绝不向任何第三方出售、出租、交易或商业化转让用户的个人数据或第三方 API 获取的数据。

3.3 Google API 专项合规声明 (Google API Services User Data Policy)#

  • 3.3.1 遵循有限使用政策 (Limited Use Requirements)：本站对通过 Google API 获取的信息的使用与传输，严格遵循 Google API Services User Data Policy，包含其“有限使用（Limited Use）”条款。
  • 3.3.2 许可数据范围：从 Google API 获取的数据仅用于在用户界面中向用户提供或改进本站的显性功能，绝不用于广告投放、数据挖掘、信用评估或转售给数据经纪商（Data Brokers）。
  • 3.3.3 人工读取限制：除非取得用户的明确同意、出于安全调查目的（如排查漏洞/滥用）、或为遵守适用法律，否则本站运营者不会人工读取通过 Google API 接入的用户数据。

3.4 数据共享与第三方基础设施#

  • 3.4.1 托管与网络基础设施：本站及 API 部署于第三方云平台（如 Cloudflare、Vercel 等），流量与基础日志由上述提供商依其隐私政策安全处理。
  • 3.4.2 法定披露：仅在适用法律强制要求、司法命令或法律程序明确要求时，本站才会在法定范围内披露必要数据。

3.5 数据安全与保存期限#

  • 3.5.1 安全防护措施：所有传输均经 TLS/HTTPS 高度加密，密码采用不可逆单向哈希算法（如 Argon2 或 Bcrypt）存储。
  • 3.5.2 保存与清理机制：
    • 账户数据保留至用户注销。
    • 访问与系统日志按自动化清理规则定期覆盖删除。
    • 通过第三方 OAuth（如 Google OAuth）获取的临时 Access Token/Refresh Token 依加密规范存储并在授权撤销时自动清空。

3.6 用户控制权与数据删除权利#

  • 3.6.1 访问与更正：用户可随时登录账户查看、修改个人基本资料。
  • 3.6.2 数据删除（被遗忘权）：
    • 用户可联系本站撤销授权并要求清空关联账户及提交的数据。
    • Google 授权撤销：用户可随时通过 Google 安全设置 (https://myaccount.google.com/permissions) 直接撤销本站对 Google 账号的访问权限。
